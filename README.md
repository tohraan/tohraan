<details>
<summary>How the graph is made</summary>

The first commits in <a href="https://github.com/tohraan/cse-lab">cse-lab</a> were backfilled with
<code>tools/build_history.py</code>, so their dates are planned rather than the day the code was first typed.
Every problem in that repo is real, tested code, and a daily workflow now releases new commits with their real dates.
The generator and the grid layout are in that repo's <code>tools/</code> folder.
